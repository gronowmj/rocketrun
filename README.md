# Rocket Run

Build the rocket, fuel it up, blast off. A single-screen jetpack shooter for the browser and iPhone.

**Play:** https://gronowmj.github.io/rocketrun/

An affectionate tribute to classic 1983 home-computer shooters. Original code, pixel art and synthesised sound; plain HTML, CSS and JavaScript with no external assets.

- Move: Left/Right arrows, A/D or Z/X. Thrust: Up, W or Shift. Fire: Space or Enter. P pauses, M mutes.
- On iPhone use the on-screen buttons (multitouch). Add to Home Screen for full screen.
